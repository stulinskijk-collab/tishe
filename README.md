# Тише — студия йоги

Статичный сайт без сборки: откройте `index.html` в браузере или загрузите папку на любой хостинг (GitHub Pages, Netlify, Vercel).

## Структура
```
index.html        разметка страницы
css/style.css     стили, цвета темы в :root
js/data.js        прайс и услуги — цены меняются здесь
js/main.js        иллюстрация, вкладки прайса, карточки, отзывы, анимации
js/booking.js     пошаговая запись: услуга → преподаватель → время → контакты
assets/           наклейки SVG и иконка сайта
```

Почта в футере — заглушка `hello@tishe.example`, замените на свой адрес в `index.html`.
